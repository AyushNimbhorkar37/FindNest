# 🏡 FindNest

FindNest is a full-stack travel accommodation platform that enables users to explore, list, and manage accommodation options through a clean, scalable, and production-ready web application.

---

## 🚀 Features

- User authentication and authorization
- Create, view, update, and delete property listings
- Review and rating system for listings
- Server-side rendering using EJS templates
- Centralized error handling and async utilities
- MVC-based structured backend architecture

---

## 🛠 Tech Stack

### Frontend
- HTML5
- CSS3
- JavaScript
- EJS (Embedded JavaScript Templates)

### Backend
- Node.js
- Express.js

### Database
- MongoDB
- Mongoose ODM

### Tools & Practices
- Git & GitHub
- RESTful APIs
- MVC Architecture
- Environment-based configuration

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository
```bash
git clone https://github.com/AyushNimbhorkar37/FindNest.git

2️⃣ Navigate to project directory
cd FindNest

3️⃣ Install dependencies
npm install

4️⃣ Environment Variables

Create a .env file in the root directory and add:

PORT=3000
MONGO_URI=your_mongodb_connection_string

5️⃣ Start the application
npm start


The app will be running at:

http://localhost:3000
